\frametitle{Overview of the OS}
\begin{theorembox}
\begin{itemize}
    \setlength{\itemsep}{8pt}
    \item An operating system is the software that \textbf{controls the execution of applications.}
    \item It acts as the \textbf{interface} between programs and the computer hardware.
    \item The OS is responsible managing I/O, processes, memory, and the CPU.
    \item The OS \textit{hides} this functionality behind a protected mode of execution called \textbf{kernel mode}, such that arbitrary programs cannot misbehave. 
\end{itemize}
\end{theorembox}

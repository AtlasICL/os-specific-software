    \item \textbf{Interface} between user programs and computer hardware.
    \item Responsible for managing I/O, processes, memory...
    \item The OS provides access to: \cite{ArpaciDusseau18-Book}
    \vspace{3pt}
    \begin{itemize}
        \setlength{\itemsep}{3pt}
        \item kernel functionality through \textbf{system calls}
        \item displaying graphics through \textbf{graphics APIs}
    \end{itemize}
\end{itemize}

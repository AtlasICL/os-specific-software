\frametitle{Graphics APIs}

\begin{block}{Overview}
  \begin{itemize}
  \setlength{\itemsep}{6pt}
    \item Interface between software and the GPU.
    \item Graphics APIs are used for displaying visuals \cite{graphics-library-wikipedia}.
  \end{itemize}

  \begin{block}{Problem}
  \begin{itemize}
    \item Many popular graphics APIs are not available on all major operating systems.
    \item For cross-compatibility, developers must rewrite rendering layers for other APIs \cite{rendering-layers}.
  \end{itemize}
\end{block}
